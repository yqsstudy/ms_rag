# 使用前准备

[请参考环境准备](atlasopdev_16_0003.html#ZH-CN_TOPIC_0000002536800441)，完成相关环境变量的配置。然后，可直接使用msOpST工具的相关功能。

- [使用此工具生成算子测试用例前，需要将要测试的算子部署到算子库中，具体请参见算子编译部署](atlasopdev_16_0024.html#ZH-CN_TOPIC_0000002504880720)。
- 若在实现算子ST功能验证时使用到AI框架，请完成所需AI框架的安装。
  - [TensorFlow框架的安装请参见《TensorFlow 1.15模型迁移指南](https://www.hiascend.com/document/detail/zh/TensorFlowCommercial/850/migration/tfmigr1/tfmigr1_000001.html)》的“环境准备 > 安装开源框架TensorFlow 1.15”章节。
  - [TensorFlow框架的安装请参见《TensorFlow 2.6.5模型迁移指南](https://www.hiascend.com/document/detail/zh/TensorFlowCommercial/850/migration/tfmigr2/tfmigr2_000001.html)》的“环境准备 > 安装开源框架TensorFlow 2.6.5”章节。
  - [PyTorch框架的安装请参见《Ascend Extension for PyTorch 软件安装指南](https://www.hiascend.com/document/detail/zh/Pytorch/730/configandinstg/instg/docs/zh/installation_guide/installation_description.md)》。
