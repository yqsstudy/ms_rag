# attr

函数

def attr(self, key, value)

函数功能

添加属性，返回当前对象，支持链式调用。在解析为trace数据之后，会显示在args中。

输入说明

key：属性名。

value：属性值。

返回值说明

Profiler返回当前对象，支持链式调用。
