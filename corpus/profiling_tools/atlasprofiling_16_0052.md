# 开启采集开关

1. 通过配置环境变量MS_TRACE_ENABLE开启Trace采集开关。

```
export MS_TRACE_ENABLE=1
```

  - 配置为1表示开启。
  - 不配置或其他值为关闭。

2. 运行MindIE Motor服务。
