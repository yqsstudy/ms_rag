# metric_inc

函数

def metric_inc(self, metric_name, metric_value)

函数功能

记录一个指标类的增量数值。

输入说明

metric_name：指标名字。

metric_value：增量数值，为负数时表示减少。

返回值说明

Profiler返回当前对象，支持链式调用。
