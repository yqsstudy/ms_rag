# metric_scope

函数

def metric_scope(self, scope_name, scope_value=0)

函数功能

定义一个指标类的作用范围，默认作用范围为全局。

输入说明

scope_name：指标范围名。

scope_value：（可选）范围标识，默认值为0。

返回值说明

Profiler返回当前对象，支持链式调用。
