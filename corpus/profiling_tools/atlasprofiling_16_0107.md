# link

函数

def link(self, from_rid, to_rid)

函数功能

记录不同资源之间的关联，实际应用时不同模块对同一个请求使用不同的编号，将两个系统的编号关联起来。

输入说明

from_rid：资源ID。

to_rid：资源ID。
