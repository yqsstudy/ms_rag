## 六、风险项

| 风险 | 影响任务 | 应对措施 |
|------|----------|----------|
| bge-large-zh模型下载慢 | T006 | 提前下载，使用镜像站 |
| Chroma兼容性问题 | T007 | 锁定版本，备选FAISS |
| LLM API调用失败 | T010, T013 | 实现重试，多提供商切换 |
| 检索效果不佳 | T009, T019 | 调整权重，增加重排序 |
